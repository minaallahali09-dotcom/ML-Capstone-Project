# ML-Capstone-Project

This project uses California Housing Dataset to predict house prices.

## Dataset
- Source: Kaggle California Housing
- Size: 20640 rows
- Target: median_house_value

## How to Run
1. Install: pip install pandas numpy scikit-learn matplotlib seaborn
2. Open notebooks in Google Colab: https://colab.research.google.com/drive/1MphuGp--RLKdVo8vzdKh73bugiFebwP7
3. Run all cells

## Models
- Regression: Linear Regression - R2 0.62
- Classification: Decision Tree - Accuracy 0.81  
- Clustering: K-Means K=5 - Silhouette 0.312
